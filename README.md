# VDra Web — VALORANTエージェントドラフト(Web版)

Discordなしで、ブラウザだけで複数人のエージェントドラフトを行うWebアプリです。
ルーム作成 → URLで招待 → チーム分け → Global Ban / Protect / Ban / Pick → 結果の保存・共有まで、すべてWeb上で完結します。

- サーバー: Node.js のみ(外部ライブラリ **ゼロ**。`npm install` 不要)
- リアルタイム同期: Server-Sent Events(全員の画面へ即時配信)+ HTTP API
- DB: SQLite(Node標準 `node:sqlite`)。`data/vdra.db` に自動作成
- エージェント情報・画像: [valorant-api.com](https://valorant-api.com) から自動取得(新エージェントも自動反映、24時間ごと更新)

---

## 1. 初期設定(最初に1回)

1. **Node.js 22.13 以上** をインストール(https://nodejs.org の LTS 版でOK)
   - 確認: `node -v` → `v22.13.0` 以上、または `v24.x`
2. ZIPを展開し、フォルダに移動
   ```bash
   cd vdra-web
   ```
3. 起動
   ```bash
   npm start
   ```
   `VDra Web → http://localhost:3000` と表示されれば成功です。
4. ブラウザで **http://localhost:3000** を開く

> 停止は `Ctrl + C`。停止時に進行中のルームは自動保存され、再起動すると途中から再開できます。

### 他の端末(スマホ・友人のPC)から参加するには

| 状況 | 方法 |
|---|---|
| 同じWi-Fi内 | `http://<起動したPCのIPアドレス>:3000` を開く。IPは Windows: `ipconfig` / Mac: `ipconfig getifaddr en0`。初回にファイアウォールの許可ダイアログが出たら「許可」 |
| インターネット越し(手軽) | [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/) を入れて `cloudflared tunnel --url http://localhost:3000` → 表示された `https://…trycloudflare.com` を共有 |
| 常時公開 | Render / Railway / VPS などにデプロイ。起動コマンド `npm start`、`data/` を永続ディスクに置く(`DATA_DIR` で指定可) |

### 環境変数(任意)

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | 待ち受けポート |
| `HOST` | 0.0.0.0 | 待ち受けアドレス(LAN公開しない場合は `127.0.0.1`) |
| `DATA_DIR` | `./data` | DB・エージェントキャッシュの保存先 |
| `VDRA_OFFLINE` | (なし) | `1` でエージェント情報の取得をしない(画像なしの内蔵リストで動作) |

## 2. 確認のときに実施すること(チェックリスト)

1人でも確認できます。**同じブラウザで別タブを開くと別プレイヤーとして参加**できます(スマホ実機での確認もおすすめ)。

**A. ルーム・参加者**
- [ ] トップで名前を入れて「CREATE ROOM」→ ロビーに移動する
- [ ] 「URLをコピー」した招待URLを別タブ/スマホで開き、名前を入れて参加できる
- [ ] トップの「ルームに参加」にルームIDを入れても参加できる
- [ ] 参加・チーム移動・名前変更が、全員の画面に即座に反映される
- [ ] ホスト: ▲▼で並び順変更、A/B/👁でチーム移動、♛でホスト譲渡、✕でキック、「ランダムでチーム分け」
- [ ] 各チーム1人以上いないと START が押せない

**B. ドラフト形式(8種類すべて)** — ロビー右の DRAFT SETTINGS で形式を選んで START
- [ ] フェーズ表示(GLOBAL BAN / PROTECT / BAN / PICK)とターンのチーム・担当者が正しい
- [ ] 上部のステップ一覧の順番が、下の「8形式のルール」どおりに進む
- [ ] 自分のターン以外は確定できない(ホスト代理がONのホストは除く)
- [ ] Ban済み・Global Ban済み・Pick済みのエージェントは選べない(暗転・斜線・バッジ表示)
- [ ] 形式6・8: 相手がProtectしたエージェントはBan/Pickできない(🛡表示)
- [ ] 形式1・2: 同じエージェントを両チームがPickできる(同じチーム内では不可)
- [ ] ロール絞り込み・検索・「選択可能のみ」が効く
- [ ] エージェントをクリック → 大きく表示 → 「LOCK IN / BAN / PROTECT」で確定(ダブルクリック、Enterでも確定)
- [ ] 相手の画面でも、選択中のエージェントが「○○が検討中」と表示される

**C. タイマー・異常系**
- [ ] 30秒放置すると、検討中のエージェント(なければランダム)が自動確定し「AUTO」と表示される
- [ ] ホストの「一時停止 / 再開 / ドラフト中止」が全員に反映される
- [ ] 2つのタブで同時に確定を連打しても、1手しか進まない
- [ ] ドラフト中にタブを閉じて開き直す・リロードする → 同じプレイヤーとして復帰する
- [ ] Wi-Fiを一瞬切る → 「再接続中…」表示の後、自動で最新状態に戻る
- [ ] ドラフト中にサーバーを `Ctrl+C` で止めて再起動 → 途中から再開できる
- [ ] 担当プレイヤーがオフラインのとき、同じチームのキャプテン(またはチームメイト)が代わりに操作できる

**D. 結果**
- [ ] ドラフト終了で両チームのPick・Ban・Protect・Global Banが一覧表示される
- [ ] 「結果URLをコピー」した `/r/xxxx` を別ブラウザで開いても結果が見られる(DBに保存済み)
- [ ] 「テキストでコピー」「JSONで保存」ができる
- [ ] ホストの「ロビーに戻る」で同じメンバーのまま次のドラフトへ。ロビーの HISTORY に過去結果が残る

**E. 画面**
- [ ] PC(1920 / 1440幅)、タブレット、スマホ(縦)で崩れない
- [ ] エージェント画像が表示される(サーバー起動ログに `loaded NN agents from valorant-api.com` と出ていればOK)

> 気になった点は「形式○のステップ△で□□になった」のように伝えてもらえれば修正します。

## 3. 8つのドラフト形式(今回の仮案)

A = ATTACKERS、B = DEFENDERS。各チーム5Pick。

| # | 形式 | 進行順 | 同じエージェントを両チームPick |
|---|---|---|---|
| 1 | スタンダード | Pick: A B A B A B A B A B | 可 |
| 2 | スネーク | Pick: A B B A A B B A A B | 可 |
| 3 | Ban＋スタンダード | Ban: A B A B → Pick: 交互 | 不可 |
| 4 | Ban＋スネーク | Ban: A B A B → Pick: スネーク | 不可 |
| 5 | トーナメント | Ban: A B A B → Pick: A B B A A B → Ban: B A B A → Pick: B A A B | 不可 |
| 6 | Protect＋Ban＋Pick | Protect: A B → Ban: A B A B → Pick: スネーク | 不可 |
| 7 | Global Ban＋スタンダード | Global Ban: A B A B → Pick: 交互 | 不可 |
| 8 | フル | Global Ban: A B → Protect: A B → Ban: A B A B → Pick: スネーク | 不可 |

- 「両チームPick可/不可」は形式ごとの既定値です。ロビーの設定でホストが上書きできます。
- 形式の定義は `src/systems.js` にまとまっています。順番やBan数の変更はこのファイルだけで完結します。

### 共通ルール
- **Pick担当**: チーム内の並び順で1人ずつ(5人未満なら順番に繰り返し)
- **Ban / Protect / Global Ban担当**: キャプテン(チームの1番目)
- **Global Ban**: 以後すべての操作で使用不可 / **Ban**: 両チーム使用不可 / **Protect**: 相手チームはBanできない(Pick不可の形式では相手Pickも不可)
- Pick済みのエージェントは後からBanできない(トーナメントの2回目Ban)
- **ホスト代理操作**(既定ON): ホストは全ターンを操作可能。大会運営や動作確認向け。OFFにすると担当者のみ
- **担当者が切断中**: キャプテンが代理可能。キャプテンも切断中ならチームの誰でも可
- **時間切れ**: 検討中のエージェント → なければ選択可能なものからランダムで自動確定

## 4. Discord Bot版からの変更点と理由

元のBotのソースコードを参照できなかったため、記録にある仕様(Global Ban / Protect / Ban / Pick、8形式)と移行依頼書をもとに **Web版として新規実装** しています。

| Discord版 | Web版 | 理由・影響 |
|---|---|---|
| スラッシュコマンド | 画面のボタン操作 | Discord不要にするため |
| Discordユーザー | 名前を入れて参加(アカウント登録なし) | 招待URLだけで参加できるようにするため。本人確認はブラウザに保存されるトークンで行う |
| チャンネル | ルーム(6文字ID・招待URL) | — |
| メッセージ更新 | リアルタイム同期(SSE) | 全員の画面を同時に更新するため |
| — | ターン制限時間・自動選択・一時停止 | 切断や放置でドラフトが止まらないようにするため(今回追加) |
| — | 結果の保存・共有URL・履歴 | 依頼書の「結果の保存・共有」に対応 |

**8形式の中身は仮案です。** 元Botと違う部分があれば `src/systems.js` を修正します。

## 5. 構成

```
vdra-web/
├─ server.js            起動スクリプト
├─ src/
│  ├─ app.js            HTTPサーバー / API / SSE / タイマー / 復元
│  ├─ engine.js         ドラフト進行ロジック(ルール・担当者判定・検証)
│  ├─ systems.js        8つのドラフト形式の定義
│  ├─ agents.js         エージェント情報の取得・キャッシュ
│  └─ db.js             SQLite保存
├─ public/              画面(index.html / app.js / style.css)
├─ test/                自動テスト(`npm test`)
└─ data/                実行時に自動作成(DB・キャッシュ)
```

### 状態が壊れない仕組み
- ドラフト状態はサーバーだけが持ち、ブラウザは表示のみ
- 確定操作は「どのステップへの操作か」を送り、既に進んでいれば拒否(連打・同時押し対策)
- 各操作にIDを付け、通信エラーで再送されても二重に反映しない
- 変更のたびにSQLiteへ保存し、サーバー再起動時に復元(タイマーも再開)
- 24時間操作のないルームは自動削除(結果は残ります)

### テスト
```bash
npm test
```
エンジン単体テスト(全8形式の完走、ルール違反の拒否、Protect/Global Ban、時間切れ、切断時の代理)と、
サーバー結合テスト(10人同時接続で全8形式を実施し全員の状態一致を確認、同時80リクエストで1手のみ反映、
切断→再接続、サーバー再起動からの復元、認証・キック)を含みます。
