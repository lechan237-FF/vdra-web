# V Dra — VALORANT Map & Agent Draft (Web)

ブラウザだけで、複数人のマップドラフト(Bo3/Bo5)とエージェントドラフトを行うWebアプリです。

- サーバー: Node.js のみ(外部ライブラリなし、`npm install` 不要)
- 同期: Server-Sent Events。チームごとに別の内容を配信し、Blind系で非公開の選択は相手チームに送信しません
- DB: SQLite(Node標準)。`data/vdra.db` に自動作成されます
- エージェント・マップ情報: valorant-api.com から自動で取得し、24時間ごとに更新します。マップは通常の爆破マップだけを使います

## 起動
1. Node.js 22.13 以上をインストールします
2. このフォルダで `npm start` を実行します
3. http://localhost:3000 を開きます

| 環境変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | 待ち受けポート |
| `HOST` | 0.0.0.0 | 待ち受けアドレス |
| `DATA_DIR` | `./data` | DBとキャッシュの保存先(Railway等では Volume を指定) |
| `VDRA_OFFLINE` | — | `1` にすると外部APIを使わず、内蔵リストで動きます(画像なし) |

GitHubにアップロードするのは `public/` `src/` `test/` `server.js` `package.json` `README.md` `REPORT.md` だけです(`data/` は不要)。

## 進行
1. ロビーでホストが設定します
   - モード: Agent Draft Only / Map + Agent Draft(Bo3・Bo5)
   - ドラフト方式・順序・数量
   - エージェント Global Ban
   - マップ Global Ban(残りが7マップになるまで)
2. Map + Agent の場合はマップドラフトを行います
   - 7マップでBan/Pickを行い、各チームの回数は固定、順番は毎回ランダムです(Bo3:各チームBan2・Pick1、Bo5:各チームBan1・Pick2)
   - マップをPickした直後に、Pickしていないチームが攻守を選びます
   - 最後に残ったマップがDeciderで、攻守はランダムで決まります
3. マップごとにエージェントドラフトを行います
   - 先攻はマップごとに交代します(Map1はA、Map2はB…)
   - 1マップ終わると8秒後に自動で次のマップへ進みます(ホストは「すぐに次へ」で早めることもできます)
4. 結果画面ではマップごとにタブを切り替えて確認できます。URLの共有、テキストコピー、JSON保存ができます

## 8つの方式
記号:Protect `()`、Ban `{}`、Pick `[]`

| # | 方式 | 進行 | 主なルール |
|---|---|---|---|
| 1 | Normal | `[A][B]…` | チーム間・チーム内とも同じエージェント不可 |
| 2 | Ban | `{A}{B}…` → Pick | Banは両チームに適用。同じエージェントの重複Ban不可。Ban数1〜3 |
| 3 | Enemy Ban | `{A}'{B}'…` → Pick | 自チームのBanは敵チームにだけ適用。敵がBanしたエージェントはBan不可 |
| 4 | Protect Ban | `(A)(B)` → Ban → Pick | Protectされたエージェントは敵チームがBan不可(Pickは可)。Protect数1〜2 |
| 5 | Head Protect Ban | 同上 | Protectされたエージェントは敵チームがBanもPickも不可 |
| 6 | Blind Ban Pick | 公開Ban → 同時非公開Pick ×5 | 相手チームとのミラーPick可。Ban数2〜4 |
| 7 | Blind Enemy Ban Pick | 同時非公開Ban → 同時非公開Pick | Banは敵チームのみに適用。重複Ban・ミラーPick可。Ban数2〜4(既定4) |
| 8 | Fearless Blind Pick | 各マップで同時非公開Pick | Bo3/Bo5専用。前のマップで自チームが使ったエージェントは以降使えない(敵チームの履歴は影響しない) |

- Standard は A B A B、Snake は A B B A A B… の順です。フェーズごとに先攻チームから始まります
- 方式の定義は `src/methods.js` にデータとして書いてあります。方式ごとに処理を複製していません
- 担当者
  - 順番に選ぶPick:チームの並び順で1人ずつ担当します
  - Ban、Protect、マップ操作、攻守選択:キャプテン(チームの1番目)が担当します
  - 同時Pick:各自が自分の枠を選びます。キャプテンは全枠を代わりに選べます
- 時間切れのとき
  - 順番に選ぶ操作:検討中のエージェントを確定します。なければランダムで確定します
  - 同時Pick:未選択の枠をランダムで埋めます
  - 同時Ban:未選択分はBanなしになります
  - 同時フェーズの制限時間は「1手の秒数 × 選ぶ数」です
- ホストの代理操作はBlind系の非公開フェーズでは自チーム分だけに限られます。相手チームの選択は見ることも操作することもできません

## ルームとホスト
- チーム名はロビーのチーム表示に直接入力します。入力できるのはホストとそのチームのキャプテンです。空欄のまま開始すると VORTEX / OBSIDIAN になります
- ホストが退出・切断すると、オンラインの参加者のうち参加順が最も早い人にホストが自動で移ります。ホストはいつでも手動で譲ることもできます
- 最後の1人が退出するとルームは削除されます
- ドラフト中に退出した人のPick枠は、同じチームの残りのメンバーに振り直されます
